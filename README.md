# Baby shower questionnaire

A one-page questionnaire for the mom-to-be. She types her answers in and hits send;
the responses are emailed via [FormSubmit](https://formsubmit.co).

- `index.html` — the questionnaire
- `thanks.html` — confirmation page shown after sending

Answers are also kept in the browser's local storage as she types, so she can
close the tab and come back to finish later.
